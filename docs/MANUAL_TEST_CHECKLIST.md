# Lista kontrolna do sprawdzenia na prawdziwym telewizorze

Tego **nie da się** zweryfikować automatycznie – wykonaj po instalacji APK.

- [ ] Aplikacja uruchamia się z launchera Android TV, ikona i banner wyglądają poprawnie.
- [ ] Ekran główny: fokus startuje na „Zaczynamy”, strzałki pilota przechodzą między 4 kafelkami, OK uruchamia.
- [ ] **Wybierz kategorię:** wszystkie 23 kategorie widoczne i *nie znikają*; strzałki góra/dół przewijają siatkę; OK otwiera naukę.
- [ ] Ilustracje są widoczne (menu, kategorie, nauka) i ostre w 1080p/4K.
- [ ] Nauka: klawiatura USB **i** Bluetooth wpisują litery bez klikania w pole; Backspace cofa; Esc/Wstecz wychodzi.
- [ ] Klawiatura z polskim układem: ą ć ę ł ń ó ś ź ż (AltGr) są przyjmowane; bez ogonków też.
- [ ] Przytrzymanie klawisza nie wpisuje serii liter; klawisze funkcyjne (F1…, Ctrl, Alt) nic nie psują.
- [ ] Po poprawnym słowie: krótka pauza, przejście dalej; klawisze w pauzie nie trafiają do następnego słowa.
- [ ] Wymowa po polsku, spokojne tempo; „Posłuchaj” powtarza słowo bez utraty wpisanych liter.
- [ ] Telewizor bez polskiego głosu: pojawia się informacja, „Dla rodziców → Ustaw głos” otwiera ustawienia.
- [ ] Zamknięcie i ponowne uruchomienie: postępy zachowane („Postępy”, kolejne słowa w „Zaczynamy”).
- [ ] Marginesy bezpieczne (nic nie ucięte przez overscan), czytelność z 3 m.
- [ ] „Dla rodziców” wymaga wpisania słowa OPIEKUN; „Wyczyść postępy” wymaga potwierdzenia.
